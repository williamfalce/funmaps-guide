# Brevo email sources

`welcome-email.html` is the source for the Brevo transactional template #8
("Welcome message_step_#4"), sent by the "Welcome message" automation when a
contact is added to the "FunMaps Newsletter" list (#3).

It links to the permanent addresses https://compass.funmaps.com/guide and
https://compass.funmaps.com/newsletter. Where those point is set in the admin
screen (Settings → Newsletter & Guide), so the email doesn't need editing each
quarter.
